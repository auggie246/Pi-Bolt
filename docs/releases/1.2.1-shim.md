Pi-Bolt 1.2.1, with the Herdr integration from [#157](https://github.com/auggie246/Pi-Bolt/pull/157), built from this tag.

1.2.1's own notes are [1.2.1.md](https://github.com/auggie246/Pi-Bolt/blob/bolt-v1.2.1-shim/docs/releases/1.2.1.md). The tag's
history is `e1eb3f7` (1.2.1) with the merges after it: automatic updates (#319) and Android CodeQL (#244), then the Herdr shim
(#157). `VERSION` is unchanged at 1.2.1, so binaries report `Pi-Bolt 1.2.1`.

### Unsigned

This fork has no release key, so `SHA256SUMS` has no `SHA256SUMS.sig`: `install.sh` and `pi-bolt update` refuse these archives
(every release since 0.6.0 is signed). Unpack one by hand, or run `install.sh` with `PIBOLT_UNVERIFIED=1`.

### Added

- **`--herdr-pi`** reports as Herdr's own Pi integration (`source=herdr:pi`, `agent=pi`), so Herdr stores the pane's
  `agent_session`, and re-execs under the process name `pi` on Linux and macOS. On Windows the process must start from a file
  named `pi.exe`, a hardlink or a copy; otherwise a startup warning says it reports as `pi-bolt`.
- **The reported resume command carries `--herdr-pi`**, so a restored session reports the same way.
- **Docs**: the README "Herdr" section and a `herdr agent list` entry in `docs/TROUBLESHOOTING.md`.

### Fixed

- A refused Herdr session report no longer holds back state reports.
